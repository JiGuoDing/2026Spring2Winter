# 想法记录

## Ray 替代 Flink

## 异构算力资源调度

部署模型或智能体时，应当部署到哪种类型的 GPU？（需要对模型与 GPU 进行联合建模）（利用 Ray 的标签功能）

是否可以把不同模型部署到一张 GPU 上以提高资源利用率？

在有限的显存下放置能使收益最高的模型组合（比如一个大模型和多个小模型或两个大模型）

## 大小模型协同

地球物理大模型主要任务分为四类：

- 查询
- 解释
- 分析
- 预测

实现**智能路由**机制，查询、解释任务优先路由到小模型，分析、预测任务优先路由到大模型。（偏向于 Agent 形式的大模型推理）（一个路由器算子，为推理请求打标签：query, explanation, analysis, prediction）

设计**智能部署**策略，基于请求类型（此处适合离线任务），找出最优大小模型组合，再找出在异构算力资源上的最优放置策略。（这里的放置策略应当是指部署一个 Agent）（这里也需要利用 Ray 的标签功能）
