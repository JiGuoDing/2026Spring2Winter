**Q1｜命题1、2 是把定义抄了两遍，你的"价值建模"没有定理。**
NV(REUSE)−NV(VERIFY) 就是三式相减；命题2 的 λ 阈值来自 NV 对 λ 线性，线性函数过零必然单调。三动作（付 C_v 看一眼再决定）是 ski-rental / rent-or-buy 的标准变体，代价感知阈值在 GDSF/LCFU 时代就有。而命题1 第 3 条（617 行）自认：弱验证器下 VERIFY 永远劣于 REUSE——贡献3 首先是负结果。全文无竞争比、后悔界、可行性定理。
判定：部分。设计稿 604–652 有推导，1127 行自认"不保证最优"，1918–1926 用 ILP 量 gap；但 920 行仍把"阈值结构"列为贡献1。
糟糕回答："我们是系统论文，不做理论。"——那为什么写成"命题"还当贡献？
过关要素：降为引理；补固定 q,L 下 break-even 唯一性与风险预算可行的充分条件；或把贡献改写成"决策规则 + 校准/OPE 评估协议"。

**Q2｜你的 L 用什么单位？章内两处口径互相打脸。**

判定：未回答（1.2 单标量口径与 1.3.2 不相加口径并存）。
糟糕回答："实验里就统一用耗时，简单。"——那风险不是风险，是延迟罚金。
过关要素：全章锁死约束口径（δ 管风险、W 用 λ·w 向量计价、L 只出 L∈{1×,10×,100×} 敏感性曲线）；删掉"端到端耗时统一"；主表不出现 q·L 标量和。

**Q3｜q 是判官标的，L 是判官标的，端到端标签还是判官标的。**
设计稿 731 行让 q_total 直接在端到端标签上校准，而标签来自 LLM judge。判官系统性偏松 10%，你的 q^UCB ≤ δ 就整体偏移，且是自证。771–774 的 Mondrian/块 conformal 只解决相关性与分组，不解决漂移：版本一变，交换性就没了——而这正是你要管的场景。
判定：部分。初稿 302 行只写"人工或可信标注抽样比较"，没规模、没协议。
糟糕回答："我们抽样人工校验。"

**Q4｜"未登记依赖率"的分母不存在，所以安全性主张不可证伪。**
设计稿 1916 行承认 INV-1 只在"相对已记录依赖"成立，2646 行说"单独报告未登记率"。可你怎么统计你不知道的依赖？未登记的不在你的分母里。真实 Agent 的依赖大量隐式（prompt 拼接、模型行为、上游工具状态），A5（118 行）一句"网关能提供"就把它变成假设。于是"依赖感知"退化为"登记感知"——相比 TTL，你只是把时钟换成了"我以为我知道的依赖"。
判定：部分。初稿 216 行诚实声明了边界，但没给测量法。
糟糕回答："依赖登记是准入条件。"——登记不全的条目永远进不来，命中率还剩多少？
过关要素：可执行的依赖覆盖审计（注入式故障：改一个未登记依赖，看是否被复用）；报"审计发现率"而非"未登记率"；安全性主张限定在已审计依赖集上。

**Q5｜淘汰换成 LCFU、只留刷新和失效，净收益剩多少？你没有这个实验。**

判定：部分（要求认了，设计缺位）。
糟糕回答："E2.5 比了最佳单动作。"——那是联合 vs 单体，不是"我的刷新 + 别人的淘汰"。
过关要素：替换式因子设计（淘汰 ∈ {价值排序, LCFU} × 刷新 ∈ {级联, TTL}）+ 最强工程组合基线（vCache 门控 + 反向索引 + TTL + 风险预算），报边际贡献与交互项。

**Q6｜四类对象：同构则是拼装，异构则做不完。**
决策核对四类完全一样（同一 NV、同一三动作），差异全在有效性特征表和验证器——那"异质"是特征工程，不是方法。反过来，act/plan 要真做，得有真实工具和真实执行来标 q，而设计稿 2634–2635 自认没有公开工件与质量标签。参数只在 resp/rag 上估出来，却在四类上主张。
判定：部分。C10、E1.1c 设了"不可由 resp/rag 风险替代"的门槛，但证据不存在。
糟糕回答："我们有统一接口。"——接口是抽象，不是贡献。
过关要素：resp/rag 实证，act/plan 只做接口验证并标注"未标定"；或给出一个异构性导致决策翻转的实例（同一 (r,i)，不同层选不同动作）。
