# 任务说明：为具备 Flink/Ray 基础但 SQL 薄弱的准数据开发工程师制定数据仓库学习 Roadmap

## 1. 你的角色

你是一名资深数据仓库、数据工程、实时数仓、离线数仓、湖仓一体和 AI 数据平台专家。

你需要为一位即将入职数据开发工程师实习岗位的学习者，制定一份系统、可执行、分阶段的数据仓库入门与进阶学习路线。

学习者的背景如下：

- 具备 Flink 基础，并且特别熟悉 Flink。
- 具备 Ray 基础。
- 不熟悉 SQL，需要重点补齐 SQL 能力。
- 即将入职数据开发工程师岗位，工作会涉及数据仓库相关技术栈。
- 当前首要目标是胜任实习岗位中的数仓开发工作。
- 对 AI，尤其是 Agent 非常感兴趣。
- 希望未来探索 Agent 与数据仓库结合的方向，例如用 Agent 赋能数仓开发、治理、运维和分析。
- 但当前学习主体必须是数据仓库，Agent 方向只能作为扩展和长期发展方向。

### 5.10 第九阶段：Agent 赋能数仓方向

这是扩展方向，不要喧宾夺主。请明确告诉学习者：

- 入职初期应该先做好 SQL、建模、调度和数据质量。
- Agent 方向可以作为个人差异化能力和长期研究方向。
- 不建议一开始就脱离数仓本职去做泛 AI 项目。

需要覆盖以下方向：

#### 5.10.1 Text-to-SQL Agent

说明：

- 用户用自然语言提问。
- Agent 结合表结构、字段解释、指标口径生成 SQL。
- 可用于业务自助分析。

需要提醒风险：

- SQL 生成错误。
- 指标口径误用。
- 权限控制问题。
- 大查询带来资源风险。

#### 5.10.2 指标问答 Agent

说明：

- 基于指标字典、口径文档、维度信息进行问答。
- 帮助业务理解指标定义。

#### 5.10.3 元数据 Agent

说明：

- 基于表结构、字段、血缘、负责人、任务信息进行问答。
- 例如：“这个 ADS 表依赖哪些上游表？”、“这个字段来自哪里？”

#### 5.10.4 数据质量诊断 Agent

说明：

- 结合数据质量规则、调度日志、数据波动、血缘信息，辅助定位异常。
- 例如某个指标突降时，Agent 帮助定位是上游延迟、口径变更、任务失败还是数据源异常。

#### 5.10.5 数仓运维 Agent

说明：

- 辅助排查调度失败、SQL 报错、任务超时、数据倾斜、小文件等问题。
- 可以结合日志检索、规则库和历史故障案例。

#### 5.10.6 SQL Copilot

说明：

- 辅助生成 Hive SQL、Spark SQL、Flink SQL。
- 辅助解释 SQL。
- 辅助重构复杂 SQL。
- 辅助生成测试数据和数据质量规则。

需要给出一个合理的长期学习路线：

1. 先掌握数仓核心知识。
2. 再整理元数据、指标口径和数据质量规则。
3. 学习 RAG、Tool Calling、Function Calling。
4. 做一个小型数仓问答 Agent。
5. 再扩展到 SQL 生成、质量诊断和任务运维。
