# 05 实战项目：并发端口扫描器

## 项目目标

- 用一个完整的小程序把前面章节的 TCP、超时、并发控制和结果汇总串起来。
- 通过线程池控制并发数，避免同时发起过多连接。
- 只扫描本机回环地址，保证示例离线可跑。

## 运行示例

```bash
python 05_port_scanner/examples/port_scanner.py
```

## 设计要点

- 使用 `socket.create_connection` 探测端口是否开放。
- 用固定数量的 worker 控制同时进行的连接数。
- 用结果汇总输出扫描结果和耗时。

## 本章示例

- [examples/port_scanner.py](examples/port_scanner.py)

## 面试回答要点

- 端口扫描器的本质是大量短连接探测。
- 限制并发数可以减少系统调用和临时连接压力。
- 需要设置超时，否则一个卡住的端口就会拖住整个扫描流程。

## 练习题

1. 为什么端口扫描必须设置超时。
2. worker pool 为什么比无限制线程更稳妥。
3. 如何把扫描目标从单机扩展到多个主机。
4. 如何让扫描器支持取消和中断。
5. 如何输出更适合机器处理的扫描结果格式。
