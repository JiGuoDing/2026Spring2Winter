Abstract:
In heterogeneous node classification, a query can receive different class evidence from
its attributes and from the labels of nodes connected through shared entities. We study
how to construct both forms of evidence with fixed typed propagation and how to
choose a prediction rule using the current support set. We present SCETRA, a
gradient-free inference framework that constructs both forms of class evidence from
the same family of normalized typed half-path operators. For each half-path, the
operator propagates attributes to the target nodes. Its transpose accumulates support-
label mass at shared entities, whose smoothed class distributions are propagated back
to the targets. We derive exact support-deletion updates for both evidence sources,
including their availability after deletion. These updates allow SCETRA to select a
prediction rule by leave-one-out evaluation on the current support set, with a fixed rule
for one-shot supervision. On four transductive node classification benchmarks,
SCETRA achieves competitive performance against supervised baselines under full-
budget supervision and pretrained baselines under strict few-shot supervision, without
encoder pretraining or gradient updates.  Stage-wise runtime and peak GPU memory
measurements characterize the computational requirements of the proposed inference
procedure. Together, these results demonstrate the practical potential of explicit
support-conditioned class evidence while clarifying how its effectiveness depends on
evidence construction and selection.

same query. For example, a paper may resemble one research category in its textual

Representation learning oﬀers ﬂexible ways to integrate heterogeneous information
and often carries out three functions together: propagating information through typed
structure, constructing evidence that discriminates among classes, and adapting the
prediction rule. The resulting performance reﬂects both the class information available
in the observed graph and labels and how ﬁtted parameters use that information. SGC
and SIGN illustrate how propagation can be separated from parameter ﬁtting (Wu
et al. 2019; Frasca et al. 2020), and related designs explore diﬀerent ways of decou-
pling propagation and prediction (Klicpera et al. 2019; Zhang et al. 2022). SeHGNN
applies this principle to heterogeneous graphs by precomputing neighborhood aggre-
gation before learning semantic fusion (Yang et al. 2023). Label propagation and
Correct and Smooth demonstrate the predictive value of observed labels (Zhu et al.
2003; Huang et al. 2021), and work connecting graph convolution with label propaga-
tion further motivates studying this signal directly (Wang and Leskovec 2022). These
developments motivate our research question. When typed propagation is held ﬁxed,
what class evidence can be constructed directly from observed attributes and support
labels, and how can the current support set guide its use in prediction?

provide two distinct forms of class evidence. Attribute evidence compares a query
with class representatives in ﬁxed feature views, capturing similarity under diﬀer-
ent attribute and structural contexts. Entity evidence uses observed support labels
associated with shared entities, capturing class associations mediated by typed rela-
tions even when target-node attributes diﬀer. However, neither source is uniformly
informative. Attribute similarity can be ambiguous, while shared entities may have
limited labeled support or associations with multiple classes. These diﬀerences moti-
vate a common class-probability representation and a way to select how the evidence
is used in the current task. Moreover, support-based selection must account for self-
label inﬂuence, since each support contributes to the statistics used to evaluate its
own prediction.
To address these challenges, we introduce SCETRA (Support-Conditioned Evi-
dence from Typed Relations and Attributes), a gradient-free inference framework that
separates class-evidence construction from support-conditioned rule selection. SCE-
TRA uses a shared family of normalized typed half-path operators to construct both
forms of evidence. In the attribute branch, ﬁxed feature views provide class prototypes
and pooled scales for computing class probabilities. In the entity branch, the trans-
posed operators accumulate support-label mass at shared entities, whose smoothed
class distributions are propagated back to target nodes. Both branches therefore pro-
duce class probabilities that can be used individually or combined. Rather than ﬁtting
a prediction model, SCETRA selects from a prespeciﬁed family of evidence rules
through exact support leave-one-out (LOO) evaluation, removing each held-out label
from all aﬀected statistics while retaining the node and its connections in the public
graph. The selected rule is then applied using the full support set, with a predeﬁned
combination for one-shot supervision.
We evaluate SCETRA on four transductive node classiﬁcation benchmarks—
ACM, DBLP, Freebase, and RDF-MUTAG—under full-budget supervision and strict
1/3/5/10/20-shot protocols. Comparisons with supervised and pretrained baselines
assess the predictive capability of directly constructed class evidence without encoder
pretraining or gradient updates. To understand the underlying mechanisms, we ﬁrst
examine the contributions of attribute and entity evidence through evidence-restricted
controls. We then compare direct typed label propagation and smoothed entity statis-
tics under ﬁxed fusion and support-based LOO selection. These matched comparisons
reveal that the relative eﬀectiveness of entity statistics can depend on how the evidence
is selected, with diﬀerent outcomes across graphs (Table 10). A separate learned-fusion
control examines whether optimizing a small set of fusion parameters can further
improve the use of ﬁxed branch evidence (Figure 1(b)). Finally, stage-wise runtime
and peak GPU memory measurements characterize the computational requirements
of the diﬀerent approaches. Table 1 summarizes their information requirements and
gradient-based updates.

2 Related Work
Learned structural and semantic models.
GCN and GraphSAGE learn neighborhood representations (Kipf and Welling 2017;
Hamilton et al. 2017), while GAT learns attention over neighborhoods (Velikovi et al.
2018). Analyses of message passing expressiveness and low-pass behavior help separate
representational assumptions from implementation complexity (Xu et al. 2019; NT
and Maehara 2019). For heterogeneous graphs, R-GCN introduces relation-speciﬁc
transformations (Schlichtkrull et al. 2018), HAN learns attention at the node and
semantic levels (Wang et al. 2019), and HGT uses transformations and attention that
depend on node and edge types (Hu et al. 2020b). MAGNN aggregates information
within and across meta-paths (Fu et al. 2020); Graph Transformer Networks learn
composite relations for a target task (Yun et al. 2019). Together, these models learn
representations, aggregation parameters, or semantic combinations over a given graph.

HGB emphasizes input processing and evaluation and introduces Simple-HGN (Lv
et al. 2021). SeHGNN separates ﬁxed neighborhood aggregation from learned semantic
fusion (Yang et al. 2023). Our question follows this separation to class prediction: we
construct distributions from current supports and assess how much can be achieved
without ﬁtting those modules.
Propagation and direct label information.
Gaussian ﬁelds formulate graph semi-supervision through harmonic functions (Zhu
et al. 2003). GNetMine applies consistency across heterogeneous relation graphs (Ji
et al. 2010), while PathSim formalizes typed path-based peer similarity (Sun et al.
2011). Propagation can be decoupled from prediction, as in SGC, SIGN, and
APPNP (Wu et al. 2019; Frasca et al. 2020; Klicpera et al. 2019); GAMLP learns
how to combine propagated information at multiple scales (Zhang et al. 2022).
Connections between graph convolution and label propagation further clarify their
relationship (Wang and Leskovec 2022). Correct and Smooth combines a learned pre-
dictor with label-based correction and smoothing (Huang et al. 2021). These methods
motivate examining graph information separately from ﬁtted parameters.
SCETRA uses a particular support statistic at shared entities. Labels accumulate
through a typed half-path transpose; each entity’s class composition is normalized and
shrunk toward a prior before returning along the path. A direct path label propagation
control instead returns the accumulated mass before normalizing it at the ﬁnal target.
The comparison therefore changes both entity-level normalization and prior shrinkage
under the same typed propagation structure.
Few-shot adaptation.
Matching Networks, Prototypical Networks, and MAML represent metric and opti-
mization approaches to adaptation (Vinyals et al. 2016; Snell et al. 2017; Finn et al.
2017). G-Meta transfers knowledge through local graph substructures (Huang and
Zitnik 2020). Our evaluation focuses on a known class set within each public trans-
ductive graph with limited supports, rather than episodic adaptation to novel classes.
SCETRA uses prototypes in ﬁxed graph feature views and adapts a ﬁnite prediction
family without a learned task encoder.
Self-supervision and graph prompting.
Deep Graph Infomax, GraphCL, and GraphMAE learn representations through infor-
mation maximization, contrastive objectives, and masked reconstruction (Velikovi
et al. 2019; You et al. 2020; Hou et al. 2022). HeCo and HGMAE develop heteroge-
neous self-supervised objectives (Wang et al. 2021; Tian et al. 2023). GraphPrompt
and All in One connect pretraining and downstream graph tasks through prompt-
ing (Liu et al. 2023; Sun et al. 2023); HGPrompt and HetGPT address heterogeneous
prompting (Yu et al. 2024; Ma et al. 2024). MUG targets universal heterogeneous
pretraining, and CHoE uses experts conditioned on structure for prompting across
domains (Shan et al. 2026; Li et al. 2026). We evaluate pretrained baselines under the
stated information budget for the target graph and report their target labels and com-
putation explicitly. Benchmark design beneﬁts from making these information and

5 Experimental Design
Mechanism questions and datasets.
The experiments address three questions. Capability asks how much classiﬁcation
performance ﬁxed typed propagation and class evidence from the supports provide
across supervision budgets. Mechanism asks which evidence sources are useful and
how reliably selection using the support labels exploits them. Boundary asks how
fusion selected using validation data changes the use of ﬁxed evidence and in which
regimes additional learning helps. ACM, DBLP, Freebase, and RDF-MUTAG cover
diﬀerent schemas and feature conditions. RDF-MUTAG is an RDF node task, distinct
from the TU benchmark for graph classiﬁcation.

Baselines.
Full comparisons include HetSAGE, HetGCN, HAN, HGT, R-GCN, Simple-HGN, and
SeHGNN (Hamilton et al. 2017; Kipf and Welling 2017; Wang et al. 2019; Hu et al.
2020b; Schlichtkrull et al. 2018; Lv et al. 2021; Yang et al. 2023). The ﬁrst ﬁve use
documented operator recipes; Simple-HGN and SeHGNN follow ports of the author
recipes. SeHGNN’s RDF port merges predicates by pairs of node types while preserv-
ing weighted multiplicity. Few-shot comparisons include HeCo, HGMAE, HGPrompt,
MUG, and CHoE (Wang et al. 2021; Tian et al. 2023; Yu et al. 2024; Shan et al. 2026;
Li et al. 2026). MUG and CHoE pretrain without labels on the same graph under the
reported information budget. HetGPT supplies related context (Ma et al. 2024); meth-
ods without an available implementation are included only in the literature discussion.
Appendix D records recipe details.
Computation.
We separate one-time pretraining, target ﬁtting or support adaptation, learned target
encoding when measured, and ﬁnal query computation. Label independent preprocess-
ing is measured separately. Cached classiﬁer evaluation and a complete graph forward
remain distinct stages. All GPU measurements use a single NVIDIA RTX 3090. The
timing for SCETRA separates preprocessing, exact LOO selection, and ﬁnal predic-
tion on ﬁxed full and ﬁve-shot partitions, with one warmup and ﬁve timed trials.
Shared pretraining is counted once for each checkpoint identity. Memory is reported as
peak allocated CUDA memory in GiB, with pretraining and target-run peaks shown
separately when available. Appendix E records execution backends, cache boundaries,
and the scope of each measurement.

The amount of available supervision substantially aﬀects the predictive capability
of SCETRA. As the support budget increases from one to ten labels per class, its mean
Macro-F1 improves from 77.38 to 90.55 on ACM and from 52.43 to 91.80 on DBLP.
Increasing the support budget provides more observations for constructing attribute
prototypes and shared-entity class statistics. It also changes the available adaptation
mechanism: SCETRA uses a predeﬁned rule at one-shot, whereas exact support LOO
enables rule selection from three-shot onward. The observed improvements therefore
reﬂect the combined eﬀects of richer support-derived evidence and the availability of
support-based selection, rather than isolating either factor.
The performance gains nevertheless vary across graphs and supervision budgets.
HeCo remains stronger on ACM at ﬁve and ten labels per class, while HGPrompt
performs better on DBLP under one-shot supervision. Freebase presents a more
challenging setting for direct evidence construction, although SCETRA improves its
Macro-F1 from 15.52 at one-shot to 29.18 at ten-shot. These results suggest that
support-conditioned class evidence can provide a competitive alternative to pretrained
representations under limited supervision, while its eﬀectiveness remains dependent
on the graph and available support labels.

7 Discussion
The results provide a complementary perspective on heterogeneous node classiﬁca-
tion by separating the construction of class-discriminative evidence from the ﬁtting
of graph representations and prediction functions. Across the evaluated graphs, ﬁxed
typed propagation and observed support labels provide substantial predictive infor-
mation without encoder pretraining or gradient updates. However, the usefulness of
this information diﬀers across evidence sources and graphs. Attribute-based evidence
is particularly eﬀective on ACM and RDF-MUTAG, whereas entity-mediated label
associations play a more prominent role on DBLP and Freebase. These diﬀerences
suggest that neither attribute similarity nor shared-entity class associations should be
assumed to provide universally reliable evidence. Instead, their value depends on the
available graph information and the current support set.
The matched controls further show that evidence construction and rule selection
are distinct but interacting aspects of prediction. Under ﬁxed fusion, replacing direct
typed label propagation with smoothed entity statistics can either improve or degrade
performance. Allowing both statistics to use the same support-based LOO selection
changes their relative eﬀectiveness, most notably on DBLP. On Freebase, selection
reduces but does not eliminate the disadvantage of the smoothed statistic, while
on RDF-MUTAG the full-budget LOO conﬁgurations select attribute-only evidence

distinction motivates SCETRA’s separation between explicit evidence construction
and support-conditioned rule selection.
Additional parameter ﬁtting provides another way to adapt the use of constructed
evidence. The learned-fusion control shows that optimizing a small number of fusion
parameters, ﬁtting three fusion parameters on support leave-one-out predictions, can
substantially change performance even when the underlying branch evidence remains
ﬁxed. The eﬀect is concentrated in particular graphs rather than being uniformly
beneﬁcial. SCETRA instead adapts through discrete rule selection from the observed
supports. Because these alternatives diﬀer in both adaptation mechanisms and selec-
tion information, their comparison should not be interpreted as isolating the eﬀect of
gradient optimization alone. Together, they illustrate diﬀerent ways to exploit ﬁxed
class evidence and help clarify when additional learning may be useful.
Several limitations deﬁne the scope of the present ﬁndings. The evaluation con-
siders transductive node classiﬁcation with known classes, and the same inference
procedure is applied across several graph schemas without separate gradient ﬁtting.
It does not establish transfer to entirely unseen graphs or novel classes. Exact LOO
removes self-label inﬂuence from support-based evaluation but does not guarantee
that the selected rule is optimal for unlabeled queries, particularly with very limited
supports. One-shot tasks therefore rely on a predeﬁned combination, and the com-
putational cost of exact selection increases with support size. The reported eﬃciency
measurements also distinguish reusable preprocessing from support-dependent adap-
tation and prediction, rather than representing a single end-to-end cost under every
deployment scenario. These boundaries motivate further investigation of more reliable
support-based selection, broader transfer settings, and reduced adaptation costs.
8 Conclusion
We presented SCETRA, a gradient-free inference framework that constructs attribute-
prototype and shared-entity class evidence from ﬁxed typed propagation and observed
support labels. Exact support LOO enables task-conditioned selection among pre-
speciﬁed prediction rules without ﬁtting a graph encoder. Experiments across four
transductive benchmarks demonstrate the predictive capability of explicit class evi-
dence under diﬀerent supervision budgets. Matched controls further reveal that the
eﬀectiveness of entity statistics depends on how their evidence is selected, with graph-
dependent outcomes rather than a uniformly preferred construction. These ﬁndings
support explicit evidence construction and support-conditioned selection as a practical
approach to heterogeneous node classiﬁcation, while clarifying the potential beneﬁts
and remaining limitations of additional adaptation.

Appendix A
Experimental Protocols for Mechanism
Controls
A.1
Evidence Source and Selection Controls
The attribute and entity controls retain support selection within their respective can-
didate families. The ﬁxed fusion used with very few supports and uniform averaging
of 44 candidates provide two nonadaptive references. Together, these controls sepa-
rate the contribution of each evidence source from the contribution of selecting how
the evidence is used.
A.2
Matched Propagation and Support Selection
Matched propagation.
We ﬁx raw views of dimension eight, α = 4, supports, paths, and expert availability.
Entity probabilities are compared with direct PpP ⊤
p Y followed by normalization at
the target; zero mass returns the same uniform prior. The entity and ﬁxed fusion
versions are measured on ﬁve full partitions. This comparison captures the joint eﬀect
of normalization at shared entities and prior shrinkage.
Matched support selection.
Using the same paths, views, and statistics as the matched propagation control, we
cross the choice of entity statistic with exact support LOO. Both ﬁxed arms use count-
weighted fusion at T = 1. Each adaptive arm selects from eight matched rules that pair
one of four options (attribute only, entity only, balanced fusion, and count-weighted
fusion) with T ∈{0.25, 1}. Here T = 1 leaves the branch probabilities unchanged, and
the ﬁxed rule belongs to both banks.
Each fold retains the held-out node in the graph and removes its label from proto-
types, scales, entity class mass, and availability. Direct propagation also renormalizes
its returned mass after deletion. Both banks use the same LOO Macro-F1, class-
balanced Brier score, and ﬁxed candidate order for selection. The selected rule is
evaluated with all support labels restored. All four arms share each of the twenty
frozen ﬁve-shot support draws per graph and each of the ﬁve training subsets from
the full train/validation partitions. Neither panel uses a separate validation set for
selection. We compute contrasts within each support set before summarizing across
draws or partitions.
A.3
Support-LOO-Trained Fusion
The initial and learned fusion variants use the same branch evidence, constructed
from eight-dimensional raw views with α = 4. For both variants, the support set is
the union of the training and validation subsets. Starting from the initial fusion, we
optimize one branch logit and two log temperatures with Adam for 100 steps at a
learning rate of 0.05. The objective is class-balanced negative log-likelihood on exact
support leave-one-out predictions. We use the ﬁnal iterate for query prediction, with
no separate validation set for checkpoint selection.

Appendix B
Feature Preparation and Numerical
Details
Dense attributes use column medians and interquartile ranges ﬂoored at 10−6, clip-
ping to [−10, 10]; missing and constant columns contribute zero. Sparse features
use column RMS scaling without centering. Attribute-free types receive eight ﬁxed
log-transformed summaries: sum, mean, maximum, and nonzero relation fraction
over incoming and outgoing neighborhoods. Features with excess dimension use
ﬁxed-seed randomized SVD (seed 1729, eight oversampling directions, two power iter-
ations). Degenerate directions can reduce the eﬀective dimension. No label enters this
preparation.
Appendix C
Inference Procedure
Construct explicit inverse relation channels with exact weighted transposes, retaining
edge multiplicity. Enumerate schema-compatible half-paths according to the ﬁxed cap
rule. Apply the complete-product row normalization through sparse factors. Build
raw and L2 attribute views; construct prototypes, pooled scales, smoothed entity
distributions, and availability from the supports. With at least two supports per class,
delete each support’s contribution from every statistic that depends on labels, evaluate
the 44 ﬁxed rules, and select by LOO Macro-F1, balanced Brier score, and ﬁxed
index. Otherwise use the predeﬁned raw/L2 combination for limited supports. Finally
evaluate the selected rule on the requested query IDs. Caches and public feature
statistics depend only on public inputs.
Complete deletion updates numerators, denominators, and availability, remov-
ing the label contribution from shared entity statistics. All paths use receiver-
row/sender-column matrices; inverse channels retain their shared relation family.
Sparse factorization avoids materializing a dense kernel between target nodes.
Appendix D
Baseline Recipes and Information
Budgets
The supervised operator defaults use hidden dimension 64, dropout 0.5, Adam learning
rate 0.005, weight decay 0.0005, at most 200 epochs, and patience 30 in the full setting,
ordering validation Macro-F1 then Micro-F1. HetSAGE applies typed SAGEConv;
HetGCN uses a bipartite GCN port with joint indices; HAN uses typed HANConv
inputs. These ﬁxed recipes provide a common supervised comparison.
Simple-HGN follows its documented two-layer author recipe with at most 300
epochs, learning rate 0.0005, weight decay 0.0001, and validation NLL checkpointing.
SeHGNN uses 50 epochs, embedding dimension 256, hidden dimension 512, dropout
0.5, input dropout 0.1, learning rate 0.001, no weight decay, and attributes with-
out propagated labels. ACM, DBLP, and Freebase retain their documented feature
and aggregation adaptations. The RDF port represents channels at the level of node
type pairs. Equivalent execution backends retain model operations and their training
budgets while reporting costs separately.

SCETRA: Support-Conditioned Class Evidence for
Gradient-Free Heterogeneous Node Classification
Yanghui Fu1* and Guangquan Cheng1
1* Laboratory for Big Data and Decision, National University of Defense Technology,
Changsha, China .
*Corresponding author(s). E-mail(s): fyh97@nudt.edu.cn;
Contributing authors: cgq299@nudt.edu.cn;
Abstract
In heterogeneous node classification, a query can receive different class evidence from its attributes and
from the labels of nodes connected through shared entities. We study how to construct both forms of
evidence with fixed typed propagation and how to choose a prediction rule using the current support set.
We present SCETRA, a gradient-free inference framework that constructs both forms of class evidence
from the same family of normalized typed half-path operators. For each half-path, the operator prop-
agates attributes to the target nodes. Its transpose accumulates support-label mass at shared entities,
whose smoothed class distributions are propagated back to the targets. We derive exact support-deletion
updates for both evidence sources, including their availability after deletion. These updates allow SCE-
TRA to select a prediction rule by leave-one-out evaluation on the current support set, with a fixed rule
for one-shot supervision. On four transductive node classification benchmarks, SCETRA achieves com-
petitive performance against supervised baselines under full-budget supervision and pretrained baselines
under strict few-shot supervision, without encoder pretraining or gradient updates. Stage-wise runtime
and peak GPU memory measurements characterize the computational requirements of the proposed
inference procedure. Together, these results demonstrate the practical potential of explicit support-
conditioned class evidence while clarifying how its effectiveness depends on evidence construction and
selection.
Keywords: Heterogeneous graphs, Node classification, Class evidence, Gradient-free inference, Few-shot learning
