Abstract:
This study proposes an automatic classification method for English learning materials
based on the random forest (RF) algorithm. By preprocessing the text data of English
learning materials, including stop word removal and feature extraction, and combining
TF-IDF and Word2Vec technology, this paper constructs a classification model based
on the RF algorithm. In order to improve the classification performance of the model,
local mean decomposition (LMD) is used to decompose the data into time and
frequency. The LMD analysis results are combined with the RF classification algorithm
to reveal the influence of the time and frequency characteristics of text data on the
classification effect. Compared with traditional algorithms such as support vector
machine (SVM), XGBoost and convolutional neural network (CNN), RF algorithm has
better performance in multiple evaluation indicators such as mean square error (MSE),
mean absolute error (MAE) and coefficient of determination (R² ) showed significant
advantages. Further SHAP analysis revealed key features that influenced the
classification results, including “lexical difficulty”, “grammatical complexity”, and “topic
specialization”. Experimental results show that the automatic classification method
based on the RF algorithm has high accuracy and good generalization ability, can be
effectively applied to the classification task of English learning materials, and provides
new ideas and methods.

Abstract
This study proposes an automatic classification method for English learning
materials based on the random forest (RF) algorithm. By preprocessing the
text data of English learning materials, including stop word removal and feature
extraction, and combining TF-IDF and Word2Vec technology, this paper con-
structs a classification model based on the RF algorithm. In order to improve the
classification performance of the model, local mean decomposition (LMD) is used
to decompose the data into time and frequency. The LMD analysis results are
combined with the RF classification algorithm to reveal the influence of the time
and frequency characteristics of text data on the classification effect. Compared
with traditional algorithms such as support vector machine (SVM), XGBoost and
convolutional neural network (CNN), RF algorithm has better performance in
multiple evaluation indicators such as mean square error (MSE), mean absolute
error (MAE) and coefficient of determination (R² ) showed significant advantages.
Further SHAP analysis revealed key features that influenced the classification
results, including “lexical difficulty”, “grammatical complexity”, and “topic spe-
cialization”. Experimental results show that the automatic classification method
based on the RF algorithm has high accuracy and good generalization ability,
can be effectively applied to the classification task of English learning materials,
and provides new ideas and methods.

ing efficiency and personalized learning experience[10]. In recent years, with the

platforms, the types and quantities of English learning materials have increased dra-
matically[11]. How to efficiently classify these learning materials to meet the needs
of different learners has become a hot research issue[12]. Traditional English learn-
ing material classification methods are generally based on manually designed rules or
simple matching based on keywords. However, these methods are inefficient and eas-
ily affected by human factors when faced with large, complex and diverse learning
materials. In recent years, with the development of natural language processing (NLP)
technology and machine learning algorithms, automated English learning material
classification methods have gradually attracted the attention of researchers. Machine
learning methods can automatically and efficiently classify English learning materials

2.2 Application of random forest algorithm in text
classification
Random forest algorithm (RF) is an integrated learning method that is widely used
in tasks such as classification and regression[13]. Its main advantage is that it makes
decisions by combining multiple decision trees, which improves the accuracy and
stability of the model. The RF algorithm has strong robustness when dealing with
high-dimensional and complex data, and can effectively avoid overfitting problems. For
the classification of English learning materials, the RF algorithm integrates multiple
decision trees to make the classification results more stable and reliable. Existing stud-
ies have shown that the RF algorithm performs well in the field of text classification,
especially when dealing with large-scale data sets[14]. It has significant advantages. For
example, the RF algorithm has been successfully applied to tasks such as social media
text classification, news article classification, and comment sentiment analysis. Com-
pared with traditional single classifiers, the RF algorithm can improve classification
accuracy through a voting mechanism, especially in cases where data is unbalanced
or noisy. The advantage of RF is that it does not require too much feature selection
of data in advance, and can automatically evaluate the importance of each feature,
which is particularly important for processing the diverse content of English learn-
ing materials[15]. In the classification of English learning materials, the application
of RF algorithm is mainly concentrated in the following aspects: First, by extracting
features such as keywords, themes, and grammatical structures in English learning
materials, the RF algorithm is used to distinguish different categories of learning mate-
rials. Secondly, the RF algorithm can also process implicit information in the text,
mine potential feature patterns, and improve the accuracy of classification. Finally,
the training speed of the RF algorithm in practical applications is fast and suitable for
processing large-scale data sets. Therefore, it shows great potential in the automatic
classification of English learning materials.

2.4 Development Trends and Challenges
Although the English learning material classification method based on the random
forest algorithm has achieved remarkable results, it still faces some challenges and
development directions[19]. First, with the increase in the types and amount of English
learning materials, how to improve the processing efficiency of the algorithm while
ensuring the accuracy of classification is still an urgent problem to be solved. In order
to meet this challenge, researchers are exploring more efficient feature extraction tech-
niques and model optimization methods, such as the combination of deep learning
and RF algorithms, or using distributed computing frameworks to accelerate the pro-
cessing of large-scale data. Secondly, with the diversification of learners’ needs, the
classification of English learning materials is not just a single task, but also needs
to be recommended and customized according to the personalized needs of learners.
To this end, future research may combine the recommendation system with the clas-
sification algorithm, and automatically adjust the classification model by analyzing
the learner’s historical behavior and preferences to provide more accurate learning
resources. Finally, with the continuous development of natural language processing
technology, feature extraction methods based on deep learning are also being opti-
mized[20]. How to combine deep learning with traditional RF algorithms to form a
more efficient hybrid model is one of the important directions for future research.
Through these innovations, the RF algorithm is expected to play a greater role in
the automatic classification of English learning materials and promote the process of
educational informatization.

The random forest (RF) algorithm is a powerful ensemble learning method that is
widely used in classification and regression taska[25]. It has become a classic algorithm
in the field of data mining and machine learning due to its excellent generalization abil-
ity and low parameter adjustment requirements. Random forest is based on decision
trees and combines multiple weak learners, that is, multiple decision trees, through
the bagging (bootstrap aggregating) method to improve the robustness of the over-
all model. Each decision tree uses a different sample subset during training, and only
considers some features when selecting node splitting features, thereby enhancing the
diversity of the model and effectively reducing overfitting. In the task of automatic
classification of English learning materials, the RF algorithm shows unique advan-
tages. Its main advantages include resistance to overfitting, the ability to handle
high-dimensional features, and insensitivity to missing data[26]. These characteris-
tics enable RF to handle complex text data sets and are not easily disturbed by
noise and incomplete data. In addition, the RF algorithm can effectively utilize the
diversity of features and combine different feature subsets to make decisions, thereby
improving classification accuracy. Text features extracted based on methods such as
TF-IDF or word vectors (such as Word2Vec) can provide RF with rich input data,
enabling the model to better identify and classify different types of English learn-
ing materials[27].The workflow of RF usually includes the partitioning of data sets,
feature selection, model training and classification process[28]. First, the data set is
divided into a training set and a test set for training and evaluating the performance
of the model. In the feature selection stage, RF will extract effective features from
the original text based on technologies such as TF-IDF or Word2Vec, which can fully
express the semantic information of the text. Then, multiple decision trees are trained
using the training set to generate a random forest model. Each tree is trained on a
subset of data and a subset of features, and finally the classification results of each
decision tree are aggregated through a voting mechanism to finally give the optimal
classification judgment. Compared with other algorithms, RF has lower computational
complexity and moderate training time, especially when processing large-scale, high-
dimensional data, it shows stronger processing capabilities than SVM and naive Bayes
alsorithms [29]. Compared with deep learning algorithms, RF’s training time is sig-
nificantly reduced and does not require a lot of computing resources. In addition, the
decision tree of the RF model has good interpretability. Through the visualization of
the decision tree, you can clearly understand how the model makes each classifica-
tion decision, which is very important for understanding and improving the model.
In the classification task of English learning materials, the RF algorithm can effec-
tively improve the classification accuracy through its powerful classification ability,
low computational requirements and good interpretability, especially when faced with
complex features and unbalanced samples. Combining the characteristics and applica-
tions of the RF algorithm, this paper proposes an automatic classification method for
English learning materials based on the random forest alporithm[30]. Compared with
other traditional classification algorithms, RF shows obvious advantages in processing
high-dimensional text data and can provide learners with personalized and efficient
learning material recommendations.

4 Experiments and results
4.1
Data sources and preprocessing
The dataset of this study comes from a public database of English learning materials,
covering a variety of text types from basic textbooks to academic papers, to ensure
that the model can learn rich language features. In order to improve the quality and
consistency of the data, we preprocessed the original text in depth. First, we cleaned
and tokenized the text, removing meaningless characters such as stop words and punc-
tuation. Then, we used TF-IDF and Word2Vec to vectorize the text. The TF-IDF
method measures the importance of words by counting word frequency and inverse
document frequency, while Word2Vec can capture the semantic and grammatical rela-
tionships between words and map the vocabulary to a dense vector space. In order to
evaluate the performance of the model, we randomly divided the dataset into a train-
ing set, a validation set, and a test set, which were used for model training, parameter
tuning, and final evaluation, respectively.
In the feature engineering stage, we extracted six key features from the text: vocab-
ulary difficulty, grammatical complexity, topic expertise, sentiment tendency, text
length, and corpus source. Among them, vocabulary difficulty is measured by calculat-
ing the proportion of rare words and the complexity of parts of speech; grammatical
complexity is evaluated by analyzing the structural complexity of sentences; topic
expertise is determined by topic models or keyword extraction; sentiment tendency
is judged by sentiment analysis technology; text length directly counts the number
of words or sentences; corpus source reflects the source and style of the text. These
features are combined with the model to enable the model to perform fine-grained
classification of English learning materials. For example, for texts with high vocabu-
lary difficulty, complex grammar and professional topics, the model may classify them
as academic papers; while for texts with simple vocabulary, positive emotions and
short text length, the model may classify them as primary learning materials. In this
way, we can achieve accurate classification of English learning materials and provide
personalized learning resources for English learners.

5 Conclusion and discussion
This study uses the LMD sequence decomposition method to analyze the text data
of English learning materials and achieves good experimental results. First, the
display of the LMD three-dimensional modal amplitude diagram effectively reveals
the distribution of text data in the time-frequency domain, providing strong support
for subsequent feature extraction and analysis. Through the LMD decomposition
diagram, we can decompose the text signal into multiple intrinsic mode functions
(IMFs), which represent the importance of the signal at different frequency com-
ponents. Especially for English learning materials, the LMD method can help us
understand the impact of different frequency components on classification, so as to
dig deeper into the semantic information in the text. In addition, the display of the

LMD spectrum diagram clearly shows the energy distribution of each frequency com-

of machine learning models, SHAP analysis provides us with important information
about the model decision process. Through the SHAP analysis diagram, we can intu-
itively understand the key features that affect the classification of English learning
materials, such as vocabulary difficulty, grammatical complexity, and subject exper-
tise. This shows that the classification decision of the model is not only based on the
language difficulty of the text, but also considers the relevance of grammatical struc-
ture and subject, so that the model can accurately distinguish different categories of
learning materials. This analysis result is of great significance for improving feature
selection and optimizing models. From the perspective of algorithm comparison, the
Random Forest (RF) algorithm performed the best in this study. The RF algorithm
surpassed other common machine learning algorithms such as support vector machine
(SVM), XGBoost, and convolutional neural network (CNN) in multiple evaluation
indicators. Specifically, the RF algorithm achieved the best results in mean absolute
error (MAE), mean square error (MSE), and coefficient of determination (R²). This
result shows that the RF algorithm can maintain high prediction accuracy and strong
generalization ability when processing text data of English learning materials. Its
ensemble learning characteristics, especially by building multiple decision trees and
adopting a voting mechanism, make the RF algorithm particularly outstanding in
preventing overfitting. In addition, the feature selection ability of the RF algorithm
also provides support for the interpretability of the model, and can identify the fea-
tures that have the greatest impact on the classification results. Compared with the
RF algorithm, other algorithms such as SVM, XGBoost, and CNN have certain limi-
tations when processing this dataset. The SVM algorithm is prone to overfitting or
underfitting when processing high-dimensional features, resulting in weak prediction
performance; although XGBoost performs well on some data sets, its performance is
still inferior to the RF algorithm in the English learning material classification task;
the CNN algorithm shows large fluctuations, indicating that its adaptability in text
classification tasks is poor, which may be because the CNN algorithm is more suitable
for processing image data when extracting features, and has certain limitations in
processing text data. Combined with the above analysis, the experimental results of
this study show that the RF algorithm has significant advantages in the classification
task of English learning materials. Its excellent prediction performance and good
generalization ability make it an ideal choice for handling this task. However, despite
the excellent performance of the RF algorithm, future research can still explore more
algorithms and methods, such as deep learning models or other integrated algorithms,
to further improve the classification accuracy. In addition, the application of the
LMD sequence decomposition method in text data analysis also provides new ideas
for future research. In the future, more time-frequency analysis techniques can be
combined to further improve the interpretability and accuracy of the model.
