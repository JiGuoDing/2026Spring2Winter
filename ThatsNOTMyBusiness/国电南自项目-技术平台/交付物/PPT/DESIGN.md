# DESIGN.md · 集团级多租户技术平台架构设计方案 · 汇报 PPT

三套 deck（客户交流 20 页 / 内部预演 12 页 / 决策汇报 8 页）共用本设计基线，B、C 只做减法，不改口径。

## ① 画布与安全区
- 画布 1280×720；padding 左右 60 / 上 60 / 下 60；内容区 1160×600（y 60–660）
- 页眉区 y 60–100（幕标 + 章节号，14px）；标题基线 y≈110–150（32–40px）；正文自 y 168 起
- 页尾固定 y 670（14px 灰）：左"集团级多租户技术平台架构设计方案 · v0.1"，右"07 / 20"
- 封面 / 章节 / 结尾页不出页尾

## ② 配色（仅 6 色，不新增）
| 槽位 | 值 | 用途 |
|---|---|---|
| 主色 accent | `#1F3864` | 标题、编号、结论条底、关键数字 |
| 辅色 surface | `#F2F5F9` | 浅底块（一页 ≤2 处） |
| 强调 accent_l | `#2E6DA4` | 图内次级块、箭头、表格表头 |
| 红线 red | `#B3261E` | 仅"禁止 / 否决 / 回写×"，不当装饰 |
| 正文 body | `#3D4C63` | 正文与表内文字 |
| 辅助 muted | `#7A8699` | 注释、来源、页尾 |
| 线 line | `#D9DEE7` | 1px 分隔线、表格线 |

## ③ 字体与字号
- 中文 `Microsoft YaHei`（标题 Bold / 正文 Regular）；数字随中文字体，成列数字等宽
- 封面主标 64 / 章节大字 56 / 巨型数字 88 / 页面主标 34 / 卡片小标 22 / 正文 18 / 表 16 / 注 14
- 每页字号组合 ≤4 种；相邻层级差 ≥4px

## ④ 视觉母题
- 内容页左上角一行幕标：`01 为什么必须改`（14px，muted，编号用 accent）
- 标题下不加装饰线；分区靠留白与 1px 贯通细线（一页 ≤2 条）
- 结论条：accent 满底 + 白字，只压整页一条，不逐卡各压

## ⑤ 图形规范
- SVG 只画结构化关系：分区图、分层图、阶梯、判例对比、时序、三闸门、甘特、流程链
- 框 1px、箭头 1.25px、强调 1.5px、圆角 4；无阴影、无渐变、无图标堆砌
- 图内文字 ≥14px，标注贴线不压线；红 ✕ 只用于"不存在 / 禁止"的路径

## ⑥ 口径红线（写页面前必读）
- 只写 `管理信息区（安全Ⅲ区）`、`生产控制区（安全Ⅰ区、安全Ⅱ区）`；法规只写"27 号令"
- 分级只写 `L0/L1/L2/L3`；打分 `B/D/R/S，T=4–20`；边界 `≤6 / 7–9 / 10–13 / ≥14`
- `约 80% 的二级租户（厂站级）`、`当量 45%–55%`、`约 109.5 人月（43.5 + 34.0 + 32.0）`、`测试约 24%`、`L3 目标 ≤ 5 个集群`
- `必改 5 / 轻改 3 / 不动 2`、`拿机制不拿平台`、`二级不自管（但不锁死）`
- 不上屏：附录、条款号、客户材料页码、T/I 全表、编号矩阵全表、同业六家对比、报价
- 引注可上屏：页脚一行「依据 [X-nn]」，参考文献页只列本 deck 引用到的编号；不上完整文献表、不上链接。

## ⑦ 三套差异
- A（20 页）：红线 → 架构 → 分档 → 打分 → 判例 → 成本 → 落地 → 收口，全链
- B（12 页）：判断 + 代价 + 工作量；删合规细节、选型细节、客户行动项
- C（8 页）：结论 + 代价 + 要什么支持；不上打分表、判例、A/B 分类、配额三层
