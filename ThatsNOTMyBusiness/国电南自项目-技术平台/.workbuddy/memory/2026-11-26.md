- **关键坑（必记）**：
  1. **SVG `<text>` 以拉丁字母或数字开头时，中文全部渲染成「□」**。根因是字体回退。解决：所有 `<text>` 显式加 `fontFamily='Microsoft YaHei'`（纯中文不加也正常，但统一加最安全）。
  2. **该渲染器不支持 `<tspan>`**：用了会丢内容，只能用独立 `<text>` 元素。
  3. 表格单元格文本里的 `&lt;` 不会被解码（只有 JSX 文本节点才会），`< 5 min` 直接写 `<`；单元格内 `\n` 可正常换行。
  4. **Table 不支持 `cellStyle.width`**：列宽由内容自动分配，短列会被压到 ~60px，`编号` 会竖排。对策：首列只放 `01`/`R1`/`#` 这类极短串，或改用「分条 Box 布局」代替表格。
  5. 页面纵向留白靠 `justifyContent: 'space-between'` 分布，内容不足时下方出现大片空白。**验收方法**：`slidep screenshot` 后用 PIL 逐行统计墨迹，找 40%–92% 高度区间内最长空白段，>70 幻灯片像素即需加高。SVG 页可写脚本把 `y/y1/y2/cy/height` 与 viewBox 高同比例放大（k 倍）来拉满。
- 版式基线（沿用 `交付物/PPT/DESIGN.md`）：1280×720、padding 60、内容区 1160×600；色板 #1F3864 / #2E6DA4 / #B3261E / #3D4C63 / #7A8699 / #D9DEE7 + #F2F5F9；字号 34 标题 / 16 副标 / 14 幕标 / 16 结论条。
