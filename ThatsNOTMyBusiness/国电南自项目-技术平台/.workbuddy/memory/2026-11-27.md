## 关键经验

### 1. 无头浏览器测窄屏必须用 iframe 容器
Windows 上 `msedge --headless --window-size=390,xxx` **会被平台最小窗口宽夹到 477 CSS px**（`--headless=old` 同样），截图左裁 477→390 的内容，看起来像"页面横向溢出"，实为假象。
可靠做法：写一个 wrapper.html，内放 `<iframe width=390 height=N>`，再截 wrapper（窗口取 520 宽即可）。媒体查询以 iframe 宽度为准，得到真实 390 视口。
`--force-device-scale-factor=1` 对窗口夹取无效。

### 2. 宽 SVG 示意图在窄屏不该等比缩到读不清
`viewBox 0 0 1000 x` 的图缩到 390 宽，13px 正文变 5px。
方案：`.fig-frame{overflow-x:auto}` + `svg{min-width:760px}` + 图下加 `.fig-swipe`"图幅较宽，可左右滑动查看完整示意图"（仅 ≤720px 显示）。

### 3. 宽表在窄屏改堆叠卡片，比压字号好
`table-layout:fixed` 只是把三列压成每列 ~110px，出现一字一行的竖排。
做法：每个 `<td>` 加 `data-label="表头名"`；移动端 `table/thead/tbody/tr/td{display:block}`、隐藏 thead、每行变卡片，首列作标题条（浅色底 + `::before` 浮动右对齐的字段名小标签），其余单元格 `::before` 显示字段名。3 个表 40 个单元格脚本批量注入 `data-label`。

坑：标题条若用 `display:flex` + `::before{order:2}` 想实现"标签靠右"，标题文字较长时换行会把标签甩到上一行，从左到右顺序错乱。改用 `display:block` + `::before{float:right}` 稳定。

### 4. 后代选择器误伤占位图标
`.fig-frame svg{width:100%;min-width:640px}` 会命中 `.ph`（占位框）里的 52px 图标 svg，把它撑成 760px 巨图（移动端整块占位被拉成一屏高）。
改为 `.fig-frame > svg`（直接子代）+ 补 `.ph svg{width:52px;height:52px;min-width:0}`。**凡是给容器内 svg 写尺寸规则，都要确认是否只想命中直接子元素。**

### 5. 中文标题孤字
`text-wrap:balance` 用于 h1/h2，`text-wrap:pretty` 用于 h3/正文，能让"一套能管住 900 个租户的控制/面"变成均衡两行。
